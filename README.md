# แผงข้อความด่วน (QuickCopy Panel)

<img src="icon.png" width="72" align="right">

โปรแกรมเล็กๆ บน Windows สำหรับเก็บ **ข้อความที่ต้องพิมพ์ซ้ำๆ** เช่น คำลงท้ายหนังสือราชการ ข้อความเกษียน หรือชื่อหน่วยงาน
ไว้เป็นแผงลอยด้านขวาของจอ **คลิกข้อความแล้วกด Ctrl+V** วางในระบบ Smart Office, Word, Excel หรือ Google Form ได้เลย

## ความสามารถ

| | |
|---|---|
| แผงลอยชิดขวา | ค่าเริ่มต้นกว้างไม่เกิน 3 นิ้ว สูง 2/3 ของจอ อยู่กึ่งกลางแนวตั้ง ลากไปไว้ที่ไหนก็ได้ และลากขอบเพื่อปรับขนาดได้ |
| อยู่เหนือหน้าต่างอื่น | กดปุ่มหมุด (รูปหมุด) บนแถบหัวเพื่อเปิด/ปิด |
| System Tray | กดปุ่ม – เพื่อซ่อน แล้วคลิกไอคอนที่มุมขวาล่างเพื่อแสดงอีกครั้ง |
| คลิก = คัดลอก | **คลิกที่แผงนี้จะไม่แย่งเคอร์เซอร์** จากช่องที่คุณกำลังพิมพ์ จึงกด Ctrl+V ต่อได้ทันที ไม่ต้องคลิกกลับไปที่ช่องเดิม |
| โหมดวางอัตโนมัติ | เมนู ≡ → *คลิกแล้ววางให้ทันที* คลิกครั้งเดียวข้อความก็ไปอยู่ในช่องเลย ไม่ต้องกด Ctrl+V |
| หมวดหมู่ | แยกข้อความเป็นหมวด เช่น *ทั่วไป / หนังสือราชการ / ที่อยู่* |
| ค้นหา | พิมพ์คำค้นเพื่อกรองรายการ แล้วกด Enter เพื่อคัดลอกรายการแรก |
| คีย์ลัด | **Ctrl+Alt+Space** เปิดแผงพร้อมช่องค้นหาจากโปรแกรมไหนก็ได้ |
| ข้อความหลายบรรทัด | Shift+Enter ขึ้นบรรทัดใหม่ เหมาะกับท้ายหนังสือที่มีหลายบรรทัด |
| ตัวแปรวันที่ไทย | `{วันที่}` จะกลายเป็นวันที่ของวันนี้ตอนคัดลอก (ดูตารางด้านล่าง) |
| จัดลำดับ | ลากการ์ดขึ้นลง หรือคลิกขวา → ย้ายไปบนสุด / เลื่อนขึ้น / เลื่อนลง |
| เพิ่มได้หลายทาง | พิมพ์ + Enter, ปุ่มคลิปบอร์ด, ลากข้อความจากโปรแกรมอื่นมาวาง, นำเข้าไฟล์ .txt (บรรทัดละ 1 รายการ) |
| บันทึกอัตโนมัติ | บันทึกทุกครั้งที่แก้ไข และเก็บไฟล์สำรอง `.bak` ไว้ 1 ชุด |
| สำรองข้อมูล | เมนู ≡ → ข้อมูล → สำรอง/นำเข้า ใช้ย้ายไปเครื่องอื่นหรือแจกเพื่อนร่วมงาน |

### ตัวแปรวันที่ (แทนค่าตอนคัดลอก)

| พิมพ์ในข้อความ | ได้ผลลัพธ์ (ตัวอย่าง) |
|---|---|
| `{วันที่}` | 19 ตุลาคม 2569 |
| `{วันที่ย่อ}` | 19 ต.ค. 69 |
| `{วันที่เลขไทย}` | ๑๙ ตุลาคม ๒๕๖๙ |
| `{วันนี้}` | วันจันทร์ที่ 19 ตุลาคม 2569 |
| `{เดือนปี}` | ตุลาคม 2569 |
| `{ปี}` | 2569 |
| `{เวลา}` | 14:30 |

ตัวอย่าง: `ลงวันที่ {วันที่}` → *ลงวันที่ 19 ตุลาคม 2569*

## ดาวน์โหลดและติดตั้ง

1. ไปที่หน้า **[Releases](../../releases)** แล้วดาวน์โหลด `QuickCopyPanel.exe`
2. วางไฟล์ไว้ในโฟลเดอร์ไหนก็ได้ (เช่น `เอกสาร\QuickCopyPanel`) แล้วดับเบิลคลิกเพื่อเปิด
3. ถ้า Windows แสดงหน้าจอสีน้ำเงิน *"Windows protected your PC"* ให้กด **More info → Run anyway**
   (ขึ้นเพราะโปรแกรมไม่ได้ซื้อใบรับรองดิจิทัล)
4. เปิดเมนู ≡ → **เริ่มทำงานพร้อม Windows** ถ้าอยากให้โปรแกรมเปิดเองทุกครั้งที่เปิดเครื่อง

ใช้ได้กับ Windows 10 / 11 (และ Windows 7/8 ที่มี .NET Framework 4.5 ขึ้นไป) ไม่ต้องติดตั้งโปรแกรมอื่นเพิ่ม

## วิธีใช้งานกับ Smart Office

1. คลิกที่ช่องกรอกข้อมูลใน Smart Office (เช่น ช่องเรื่อง ช่องเกษียนหนังสือ)
2. คลิกข้อความที่ต้องการบนแผงด้านขวา (การ์ดจะเป็นสีเขียว = คัดลอกแล้ว)
3. กด **Ctrl+V** (เคอร์เซอร์ยังอยู่ที่ช่องเดิม เพราะแผงนี้ไม่แย่งเคอร์เซอร์)
   ถ้าเปิดโหมด *คลิกแล้ววางให้ทันที* ไว้ ไม่ต้องทำข้อ 3

| การกระทำ | ผลลัพธ์ |
|---|---|
| คลิกซ้ายที่การ์ด | คัดลอก |
| คลิกขวาที่การ์ด | คัดลอกแล้ววาง / แก้ไข / ทำสำเนา / ย้ายหมวด / ลบ |
| ลากการ์ด | จัดลำดับ |
| วางเมาส์ค้างบนการ์ด | ดูข้อความเต็ม และผลลัพธ์ของตัวแปร |
| ลากแถบสีน้ำเงิน | ย้ายแผง |
| ดับเบิลคลิกแถบสีน้ำเงิน | กลับไปชิดขวาเหมือนเดิม |
| Ctrl+Alt+Space | เปิดแผงและค้นหา (กดอีกครั้งเพื่อซ่อน) |
| Ctrl+F / Ctrl+N / Esc | ค้นหา / เพิ่มแบบละเอียด / กลับไปหน้าต่างเดิม |

## ที่เก็บข้อมูล

- ปกติเก็บที่ `%AppData%\QuickCopyPanel\data.json`
- **โหมดพกพา (USB):** สร้างไฟล์เปล่าชื่อ `portable.txt` ไว้ในโฟลเดอร์เดียวกับ `QuickCopyPanel.exe`
  โปรแกรมจะเก็บ `data.json` ไว้ข้างไฟล์ .exe แทน

## สร้างไฟล์ .exe เอง (สำหรับผู้พัฒนา)

ดับเบิลคลิก `build.bat` บนเครื่อง Windows ได้เลย ใช้ตัวคอมไพล์ C# ที่มากับ Windows (.NET Framework 4.x) ไม่ต้องติดตั้ง Visual Studio
ไฟล์ที่ได้จะอยู่ที่ `dist\QuickCopyPanel.exe`

ทุกครั้งที่ push ขึ้น GitHub ระบบ GitHub Actions จะคอมไพล์ให้อัตโนมัติ ส่วนการ push tag `v*` เช่น `v1.0.1` จะสร้าง Release พร้อมไฟล์ .exe

```
src/
  Program.cs          จุดเริ่มโปรแกรม, กันเปิดซ้ำ
  MainForm.cs         หน้าต่างแผง, tray, เมนู, คัดลอก/วาง
  SnippetListView.cs  รายการการ์ด (วาด, คลิก, ลากจัดลำดับ)
  Dialogs.cs          หน้าต่างเพิ่ม/แก้ไข, กล่องรับชื่อ
  Models.cs           โครงสร้างข้อมูล, อ่าน/บันทึก JSON
  Templates.cs        ตัวแปรวันที่ไทย
  Theme.cs            สี ฟอนต์ ไอคอน
  Native.cs           Windows API
```
